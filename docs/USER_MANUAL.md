# 书中织梦 · Novelborne 用户手册

> 版本 2.1.0 ｜ 从零开始，10 分钟开始你的第一次世界模拟。

## 这是什么

Novelborne 是一个由大模型驱动的**互动小说世界模拟器**。你以穿越者身份进入
原著世界（或原创世界）：模型负责写角色与场景，程序负责世界规则——剧情锚点、
任务、角色状态、收束力、金手指冷却全部由代码管理，模型"编不动"的部分会被
门禁拦下重写。你不是在和一个聊天机器人对话，而是在一个有规则的世界里行动。

## 安装与启动

### 方式一：源码运行（推荐开发者）

```bash
# 1. 安装依赖（Python 3.11+）
pip install -r requirements.txt

# 2. 构建前端（首次或前端有更新时）
cd frontend && npm install && npm run build && cd ..

# 3. 启动
python run_app.py                # 默认 0.0.0.0:8000（局域网可访问）
python run_app.py --host 127.0.0.1 --port 8000   # 仅本机
```

浏览器打开 `http://127.0.0.1:8000`。

### 方式二：发行包

下载对应平台的发行包，解压后直接运行可执行文件即可（内含已构建前端）。

## 第一次开局

### 1. 配置模型连接（右侧「模型与参数」）

1. 服务商：DeepSeek / 通义千问 / Kimi / 智谱 / OpenAI / 自定义 OpenAI 兼容
2. 填入 API Key（**只在内存中持有，绝不写入磁盘**）与 Base URL（自定义时）
3. 点击「测试」确认连接成功，选择模型

### 2. 选择模式

| | 基础模式 | 强化模式（主推） |
|---|---|---|
| 世界来源 | 作品库现成作品 / 题材碎片 | 上传完整 TXT 原著 |
| 还原度 | 轻量 | 高（锚点蒸馏+角色卡） |
| 剧情丰度 | 前两档 | 全六档 |
| 宿敌/碎锚/任务全链 | 部分 | 完整 |

强化模式需要可切章的完整 TXT（有"第X章"类章节标题），开局会自动蒸馏
剧情摘要、角色卡和锚点（右上角有进度）。

### 3. 确认设定 → 选择金手指

1. 填写穿越身份、时间点、难度、女主/同伴名册
2. 点击「确定」确认设定 → 系统推荐金手指（或自由描述后正式化）
3. 选定金手指后人物与难度锁定 → 点击「开始模拟」

强化模式：上传原著 → 校验并准备 → 开局后在聊天框输入
**「确认金手指」** → **「确认开局」** 进入第一幕。

## 游玩

### 推进剧情

- **点选项**：每回合 6 个 AI 生成的选项（字母 A–F），覆盖金手指运用与性格
  行动两种因素，各选项附带后果预告
- **自由行动**：在聊天框用自然语言描述你想做的事（能力范围内）
- **代理选择**：点击「由主角性格子智能体代选」让 AI 按你的人设替你选

### v2.1.0：正文流式草稿

强化模式组装管线现在**逐段实时推送草稿**——发出行动后几秒内开始看到正文
逐渐成形（此前的版本要等全流程结束）。后处理（润色/质量门）完成后终稿
会整体替换草稿，最终质量只升不降。

### 角色闲聊

对局中正文区下方出现「角色闲聊」：下拉选择在场角色，随时对话。闲聊
**不推进剧情、不消耗回合**——角色只会以自己的性格和你闲谈，给不了你
物品或情报。切换回合后在场角色名单自动更新。

### 任务与碎锚

- **任务**：向系统要一个任务（短/中/长），完成判定要求正文**实际写到**
  完成条件达成（证据制，不接受"我打算做"）；完成后奖励自动入账
- **碎锚**：发起碎锚挑战，逐阶段摆脱原著剧情锚点的收束；全部完成后进入
  自由剧情线（世界仍有惯性，但你已改写命运）

### 存档与读档

- 每回合自动落盘；「存档」区可另存命名存档、读取任意存档、导出小说文稿
- 页面刷新不掉档（自动找回会话）；「开启新游戏」回到全新开局状态

### 界面主题

26 款主题（现代简约/古风水墨/赛博朋克/克苏鲁/雨后彩虹/热带雨林/苍莽大漠/
无际重洋/青翠群山/入云雪峰/原始沼泽/九霄之上/风和日丽等），主题带全套配色
与纹理装饰。字号、动效、首字下沉可在「界面」区调整。

### 局域网游玩

默认监听 `0.0.0.0`，手机扫首页二维码即可在手机上继续同一局（同一 Wi-Fi）。

## Token 用量

侧栏实时显示本局 token 消耗（实测值来自模型返回的 usage，流式期间持续
跳动；估算值有标注区分）。任务提议、闲聊等独立调用即时计入。

## 常见问题

| 现象 | 处理 |
|---|---|
| 开局按钮灰色 | 未确认设定 / 未选金手指 /（强化模式）未上传 TXT |
| 强化模式开局 400 | TXT 无法切章：检查章节标题格式（需"第X章"类标记）与编码（UTF-8） |
| 提示 409 | 上一回合还在生成，请等待完成 |
| 锚点未就绪提示 | 强化模式首章锚点蒸馏中，稍候重试 |
| 聊天下拉为空 | 尚未开局，或本回合无在场角色 |
| 服务重启后丢档 | 自动从磁盘存档回填；连 404 则该局存档已被清理 |
