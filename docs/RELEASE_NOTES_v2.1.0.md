# Release Notes · v2.1.0

**书中织梦 · Novelborne** — 大模型驱动的互动小说世界模拟器

## 亮点（v2.1.0：全链路并行化）

### 生成体验
- **正文流式草稿**：强化模式组装管线（导演卷 → 段卷 → 润色 → 质量门）现在
  段卷完成即实时推送正文草稿——发出行动后数秒内开始看到正文成形（此前需
  等待全流程结束，通常 2–6 分钟）；后处理完成后终稿整体替换，质量只升不降
- **回合耗时大幅下降**：段级批改-重填、后结算（任务判定/碎锚判定/宿敌/
  角色状态 patch）、润色与选项生成全部并发化，各阶段耗时从"各步之和"
  降为"最慢一步"
- **上下文压缩离线化**：压缩不再阻塞回合结束，移到下一回合开头执行

### 生成质量
- **润色 best-of-2**：两份润色候选并发生成，规则层打分择优
- **选项 best-of-2**：两卷视角差异化（剧情走向优先 / 玩家处境优先）并发
  择优，且选项卷注入导演蓝图节拍——选项与本回合剧情走向对齐
- **任务判定 self-consistency**：两份独立判定并发投票，一致即采信，消除
  单次幻觉导致的误判完成
- **闲聊 best-of-2**：角色闲聊双候选并发择优，voice 一致性取上界

### 修复
- 角色闲聊后端路由修复（此前引用不存在的内部函数导致 500）；开局后聊天
  名册即为非空（无在场角色时回落同伴/女主名册）
- 「开启新游戏」完整重置：正文、选项、提问、金手指与设定确认、任务、
  蒸馏轮询、聊天全部回到全新开局状态
- 质量门 free 阶段权重分支 NameError 修复
- 新增 8 款主题（热带雨林/苍莽大漠/无际重洋/青翠群山/入云雪峰/原始沼泽/
  九霄之上/风和日丽），全套配色与纹理装饰

### 工程质量
- 全量 581 项单元测试通过；并行模型调用经 contextvars 快照携带 Token
  累加器，并发计量不丢不重
- 隐私清理：API key 只走内存；运行数据、本机路径、上传原著绝不入库
