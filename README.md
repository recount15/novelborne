> **v3.0.0 本机功能验收完成（2026-09-09），未公开发布。** 界面经用户验收收口；后端全量隔离回归897通过、前端27/27与构建通过。真实付费模型质量矩阵与Android构建明确未执行。为消除版权疑虑，本版本**不附带任何预置作品与角色**，从空书库、空角色库开始。

Novelborne 是互动小说世界模拟器：模型负责叙事表达，程序负责角色、原著边界、任务和状态提交。

## v3 使用重点

- **角色库以数据库为唯一活动来源。** 新的空数据库没有预装角色；旧 JSON、Markdown 和恢复包不会作为活动库自动回退。不要把旧作品编号或文件数量当作现有角色数量。
- **角色设计器统一保存。** 编辑后使用角色库保存入口，以服务端保存成功及修订号为准；不再要求先保存 persona 再保存另一份角色。未完成界面联调时，请勿把本地成功提示当作数据库验收证据。
- **仅蒸馏使用全书准备任务（fullbook）。** 上传原著、配置模型后提交，按任务状态查看进度、取消或恢复；完成准备不等于已经开局，也不应进入“已玩”作品列表。
- **阅读搜索独立于模型。** 精确搜索和文本近似（fuzzy）都查原文，不需要 API Key，不是语义问答。点击命中查看章节与高亮。
- **阅读器的两个入口边界不同。** “与人物对话”是当前章末的独立访谈，不推进游戏；“从本章开始”以本章开始前为边界，回配置确认后创建新会话，不覆盖旧局。
- **Agent 集群不是无限重写。** 调用次数、重试、并发、时间与预算有上限；模型结果须经过代码硬门禁才能提交。真实模型费用仍由服务商计费，失败或取消也可能已产生费用。

## 快速开始

需要 Python 3.10+、Node.js 18+。Python 依赖请自行安装（一键脚本只检查并提示，不自动安装）：

```bash
pip install -r requirements.txt
```

然后一键构建并启动（Windows 也可直接双击 `start.bat`）：

```bash
python setup_and_run.py
```

脚本会检查环境、构建前端并启动服务，默认地址 <http://127.0.0.1:21560/>；端口被旧版本占用时自动改用相邻端口并提示。也可以手动分步执行：

```bash
cd frontend
npm ci
npm run build
cd ..
python run_app.py --host 127.0.0.1 --port 21560
```

打开 <http://127.0.0.1:21560>。模型功能需配置 OpenAI 兼容服务；API Key 放在请求体中，不要放 URL、查询参数、截图或日志里。阅读原文搜索无需配置模型。

新环境建议先导入自己有权使用的 TXT，核对章节，再做全书准备。待任务明确 `READY` 后再尝试强化开局。`FAILED`、`INTERRUPTED`、`CANCELLED` 或进度条满格都不能替代 `READY`。

## 局域网与数据保护

仅在可信局域网需要手机访问时使用 `--host 0.0.0.0`，放行相应端口并选择正确网卡地址；默认启动器可能监听所有网卡。会话二维码和链接包含会话标识，勿公开分享，也勿直接暴露到公网。

运行数据位于所选运行目录（默认 `var/`）。升级或迁移前停服并备份数据库、会话和上传数据；旧资产隔离与恢复说明见用户手册。不要盲目执行覆盖恢复脚本。
