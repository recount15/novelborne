# 动态世界书规范

世界书将设定拆成小条目，按当前输入和最近消息关键词触发，避免把整套百科一次性塞入上下文。

## 条目字段

`id/title/keys/secondary_keys/content/category/priority/constant/scan_depth/cooldown/max_chars/position/links/enabled`

- 少量世界宪法可设 `constant=true`。
- 地点、人物、组织、能力和事件默认使用关键词触发。
- `secondary_keys` 用于别名、同义词和简称。
- `scan_depth` 限制最多扫描的最近消息层数。
- `cooldown` 防止同一条目每回合重复注入。
- `max_chars` 与回合预算共同限制上下文开销。

## 匹配与注入

1. 扫描玩家输入、最近对话和当前回合提示。
2. 统计主要关键词与别名命中，按常驻性、命中数和优先级排序。
3. 受字符预算约束选择条目；超预算条目延迟到后续回合。
4. 以 `【本回合动态世界书】` 区块注入模型上下文。
5. 将命中 ID 与冷却回合写入存档，读档后恢复。

## 当前实现边界

匹配是确定性子串匹配（大小写无关），不依赖向量库或额外模型调用，因此可离线复现与测试。当前回合默认预算 2600 字符、扫描深度 6，命中条目 ID 写入状态面板的「世界书命中」一行。冷却以回合数计：`cooldown=2` 表示命中后需间隔 2 回合才可再次注入。

世界书只说明当前相关设定，不替代原文锚点、历史摘要或状态快照。条目不能凭关键词命中自动创造人物、地点、组织或事件。
